🔥 Firebase

ربط Firebase بالمشروع — خطوة بخطوة

اتبع هذه الخطوات بالترتيب بالضبط. الوقت المتوقع: 20-30 دقيقة.

1

إنشاء مشروع Firebase

اذهب إلى console.firebase.google.com → أنشئ مشروعاً جديداً → اختر اسماً مثل "baladi-app". فعّل Google Analytics إذا أردت التتبع.

2

تثبيت FlutterFire CLI

# في الـ Terminal dart pub global activate flutterfire_cli # تأكد أنه مثبت flutterfire --version
3

ربط المشروع بـ Firebase

شغّل هذا الأمر من داخل مجلد المشروع. سيُنشئ تلقائياً ملف lib/firebase_options.dart.

# من داخل مجلد المشروع cd baladi_app flutterfire configure # اختر مشروع Firebase الذي أنشأته # اختر android و ios (أو ما تحتاجه)
4

تفعيل الخدمات في Firebase Console

من قائمة Build في الـ sidebar:

🔒 Authentication
فعّل → Phone + Google
🗃️ Firestore Database
أنشئ → Start in Test Mode
🗂️ Storage
أنشئ → Start in Test Mode
📨 Cloud Messaging
مفعّل تلقائياً
5

إعداد Google Maps API

اذهب إلى console.cloud.google.com → APIs → فعّل Maps SDK for Android + iOS → انسخ الـ API key

# Android: في AndroidManifest.xml داخل <application> <meta-data android:name="com.google.android.geo.API_KEY" android:value="YOUR_API_KEY_HERE"/> # iOS: في AppDelegate.swift import GoogleMaps GMSServices.provideAPIKey("YOUR_API_KEY_HERE")
6

تحميل خط Cairo وإضافة الـ Assets

حمّل Cairo من fonts.google.com/specimen/Cairo ثم ضع الملفات في:

assets/ └── fonts/ ├── Cairo-Regular.ttf ├── Cairo-Medium.ttf ├── Cairo-SemiBold.ttf └── Cairo-Bold.ttf
7

إضافة الـ Permissions

# Android: AndroidManifest.xml <uses-permission android:name="android.permission.INTERNET"/> <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/> <uses-permission android:name="android.permission.CAMERA"/> <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"/> # iOS: Info.plist NSLocationWhenInUseUsageDescription → "نحتاج موقعك لتحديد مكان البلاغ" NSCameraUsageDescription → "لالتقاط صور الحفر" NSPhotoLibraryUsageDescription → "لاختيار صور من معرضك"
8

تثبيت الحزم وتشغيل المشروع

flutter pub get flutter run # إذا واجهت مشكلة في iOS cd ios && pod install && cd ..
🛡️ Security Rules

قواعد الأمان

ضعها في Firebase Console → Firestore → Rules. تمنع الوصول غير المصرح به.

🗃️ Firestore Rules
rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /reports/{id} { // أي شخص يقرأ، فقط المسجل يكتب allow read: if true; allow create: if request.auth != null; allow update: if request.auth != null; allow delete: if isAdmin(); } match /users/{userId} { allow read, write: if request.auth.uid == userId; match /notifications/{n} { allow read, write: if request.auth.uid == userId; } } function isAdmin() { return get(/users/$(request.auth.uid)) .data.role == 'admin'; } } }
🗂️ Storage Rules
rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /report_images/{img} { // أي شخص يقرأ الصور allow read: if true; // المسجل يرفع بحد 5MB allow write: if request.auth != null && request.resource.size < 5242880 && request.resource.contentType .matches('image/.*'); } match /avatars/{userId} { allow read: if true; allow write: if request.auth.uid == userId && request.resource.size < 2097152; } } }
